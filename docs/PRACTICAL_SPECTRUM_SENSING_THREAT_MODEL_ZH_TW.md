# 實際頻譜感知威脅模型（繁體中文）

## 1. 適用範圍

本威脅模型針對一個**被動式射頻監測站**：SDR 接收器持續監聽指定頻段，將複數基頻 IQ 串流交給能量偵測器；偵測到活動後，系統擷取事件視窗並使用 AMC 模型判斷調變類型，最後把事件、信心分數及原始證據交給分析人員。

近期系統邊界應描述為：

> 預先通道化複數基頻串流上的能量觸發 AMC 監測器。

「預先通道化」表示上游 SDR、GNU Radio flowgraph 或既有濾波器已選出一個待監測通道。現有程式的能量偵測器只觀察該通道中能量隨時間的變化，尚不能判斷寬頻輸入中哪些頻率 bin 被佔用。因此，本威脅模型分成：

- **目前可實驗範圍：** 單一預先通道化 IQ 串流的活動偵測、事件分段及 AMC。
- **未來寬頻延伸：** 在 STFT 或 polyphase channelizer 後，針對多個子通道進行佔用偵測。完成 channelizer 前，不宣稱系統已具備寬頻頻譜感知。

## 2. 實際部署情境

### 2.1 場景

一個工業園區、研究設施或私人無線網路在合法授權範圍內部署 SDR 監測節點，用來：

1. 偵測指定通道何時出現射頻活動。
2. 建立事件的開始時間、結束時間、功率及原始 IQ 證據。
3. 以 AMC 提供可能的調變類型，協助分析人員分流事件。
4. 對低信心、模型不一致或防禦被觸發的事件提出警示。

系統**不直接發射、不自動封鎖訊號，也不自動重新分配頻譜**。因此，近期安全後果不是虛構的「自動控制平面被接管」，而是：

- 真實發射活動未被記錄，形成監測盲點。
- 假事件大量進入分析佇列，造成分析資源耗盡。
- 事件被錯誤合併、切割或分類，使證據與時間軸不可信。
- 系統長期棄權或失效，降低監測服務可用性。

### 2.2 資料流程

```text
天線／RF 前端
  -> SDR ADC 與數位下變頻
  -> 預先通道化或選頻
  -> complex64 IQ 擷取／串流
  -> 擷取健康檢查
  -> 能量偵測與噪聲底估計
  -> 事件區域擷取、合併與分段
  -> 重疊視窗／最大能量視窗選擇
  -> AWN 輸入前處理
  -> AMC 與 Top-K／其他防禦
  -> 事件層彙整、信心判斷與棄權
  -> 事件紀錄、原始 IQ 證據與分析佇列
```

## 3. 受保護資產

本研究保護的不是 RF 訊號機密性，而是監測結果的完整性與可用性：

1. **佔用判斷完整性：** 系統是否正確判斷通道在特定時間有活動。
2. **事件時間軸完整性：** 事件起訖、持續時間、分裂與合併結果是否可信。
3. **AMC 結果完整性：** 類別、信心及棄權理由是否能反映實際接收訊號。
4. **監測服務可用性：** 攻擊者不能以低成本造成持續誤報、分類洪泛或分析佇列阻塞。
5. **證據完整性：** 被偵測事件的原始 IQ、metadata、模型版本與設定可追溯且不被悄悄丟棄。
6. **失效可見性：** SDR dropped samples、模型載入失敗、NaN／Inf、削波及 backend fallback 必須被明確報告。

## 4. 系統與訊號模型

### 4.1 接收訊號

在一個預先通道化通道中，接收器觀察：

\[
y[n] = (h_s * s)[n-\tau_s] + (h_a * a)[n-\tau_a] + w[n],
\]

其中：

- \(s[n]\) 是合法發射器訊號。
- \(a[n]\) 是攻擊者經 RF 發射的波形。
- \(h_s\) 與 \(h_a\) 是合法訊號與攻擊訊號各自經歷的通道。
- \(\tau_s\) 與 \(\tau_a\) 是未知且通常不同的到達時間。
- \(w[n]\) 是接收器雜訊與其他背景干擾。

實際攻擊者不能直接把任意數位擾動 \(\delta[n]\) 寫入分類器輸入；它只能發射 \(a[n]\)，而接收端看到的是經通道、頻率偏移、相位誤差、時間偏移、ADC 量化及前端濾波後的結果。

### 4.2 目前的能量偵測

現有實作可抽象為：

\[
p[n] = |y[n]|^2,
\]

\[
\bar{p}[n] = \frac{1}{W}\sum_{i \in \mathcal{W}_n} p[i],
\]

\[
\hat{N} = \operatorname{median}_n(\bar{p}[n]), \qquad
\gamma = \alpha\hat{N},
\]

\[
m[n] = \mathbb{1}[\bar{p}[n] > \gamma],
\]

其中 \(W\) 是平滑視窗、\(\hat{N}\) 是中位數噪聲底估計、\(\alpha\) 是 `threshold_factor`。連續的 \(m[n]=1\) 會形成事件區域，鄰近區域可依 `merge_gap` 合併，再依 `min_region_len` 過濾。

這個設計揭露三個實際攻擊面：

1. 攻擊者可操控被估計的噪聲底 \(\hat{N}\)。
2. 攻擊者可在區域間填入能量，改變事件合併結果。
3. 攻擊者可操控區域內能量分布，影響最大能量視窗的選擇。

### 4.3 寬頻延伸

若未來新增 channelizer，對第 \(k\) 個頻率 bin／子通道的觀察可寫為 \(Y_k[t]\)，每個子通道具有自己的噪聲估計 \(\hat{N}_k[t]\) 與佔用狀態 \(m_k[t]\)。此時攻擊者還可能利用：

- 多子通道假佔用。
- 鄰道洩漏造成的跨通道誤報。
- channelizer 邊界上的能量分散。
- 寬頻低功率噪聲造成多個噪聲估計器同時偏移。

這些攻擊只能在 channelizer 實作並驗證後納入主要實驗結果。

## 5. 信任邊界

### 5.1 可信元件

基準威脅模型假設下列元件由防禦方控制：

- SDR 主機、作業系統與本地儲存。
- 擷取程式、能量偵測、分段器、AMC 與防禦程式碼。
- AWN checkpoint 與設定檔。
- 事件資料庫及分析介面。
- 量測實驗中的衰減器、合路器與屏蔽設備。

### 5.2 不可信輸入

- 天線收到的所有 RF 能量。
- 未經驗證的 `.cfile` 或外部 IQ 擷取檔。
- 擷取 metadata 中可能缺失或錯誤的樣本率、中心頻率、增益與時間戳。
- 模型所輸出的高信心分數；高信心不等於輸入未被攻擊。

### 5.3 另一個獨立威脅面

主機入侵、checkpoint 置換、結果檔竄改及供應鏈攻擊很重要，但它們屬於軟體完整性問題，不與 RF 波形攻擊混在同一主要實驗中。它們應由模型雜湊、簽章、最小權限與 append-only evidence store 處理。

## 6. 攻擊者模型

為兼顧實際性與安全上界，研究分成三層攻擊者，不用單一模糊的「white-box attacker」涵蓋所有情況。

### A0：數位注入攻擊者（除錯與安全上界）

- 可直接修改離線 IQ tensor。
- 知道完整管線、模型權重與參數。
- 可計算梯度並精確控制樣本時間。
- 不受 RF 通道與同步限制。

A0 用於驗證演算法、尋找最壞情況及比較既有 FGSM／PGD／CW 文獻，但**不能單獨支撐 OTA 可行性主張**。

### A1：受控 RF 攻擊者（主要實際模型）

- 在監測接收器可接收範圍內放置一台獨立 SDR 發射器。
- 可監聽合法活動並在有限反應延遲後發射。
- 可選擇中心頻率、頻寬、波形、發射功率、時間長度與 duty cycle。
- 知道偵測、分段、前處理、防禦與模型設計；可取得相同模型或代理模型。
- 可估計自身到接收器的通道，但不知道瞬時接收器雜訊，也無法精確控制合法發射器的通道。
- 與合法發射器沒有共同時鐘或相位同步。
- 不能修改接收主機、程式、checkpoint、事件資料庫或擷取 metadata。

A1 是主要論文威脅模型，因為它符合「附近攻擊者以商用 SDR 發射加性波形」的情境。

### A2：查詢式黑箱 RF 攻擊者

- 不知道模型權重或完整防禦參數。
- 可能知道大致架構、視窗長度及監測頻段。
- 只能透過有限的外部回饋推測結果，例如可觀察的告警、操作人員反應或測試 API。
- 受限於查詢次數、發射時間與總能量。

A2 用來評估 transfer attack、Square／SPSA／NES 類方法及真實部署中資訊不足的攻擊者。

## 7. 實際攻擊目標

### G1：Noise-floor poisoning（噪聲底污染／感知隱藏）

攻擊者在監測視窗的大部分時間發射低功率、近似平穩的同頻或帶限噪聲，提高中位數噪聲估計 \(\hat{N}\)，進而提高門檻 \(\gamma=\alpha\hat{N}\)。較弱的合法 burst 可能因此低於新門檻而未形成事件。

這比「用加性訊號降低瞬時能量」更實際，因為攻擊者不需要與合法訊號精確反相。實驗應量測：

- 攻擊 duty cycle 與監測估計視窗長度。
- 接收端 jammer-to-noise ratio（JNR）。
- 合法 signal-to-jammer ratio（SJR）。
- 合法事件偵測率下降幅度。
- 攻擊本身是否產生可見事件或異常噪聲警示。

防禦方向包括凍結／限制噪聲底更新率、排除疑似佔用樣本、使用多分位數與長短期估計差異，以及對噪聲底突升產生告警。

### G2：Phantom occupancy（假佔用與誤報洪泛）

攻擊者發射大量短 burst，使其超過能量門檻並通過 `min_region_len`，迫使系統建立事件、執行 AMC、保存證據及通知分析人員。目標不是佔滿整個頻段，而是以最低平均發射功率最大化：

- 每分鐘假事件數。
- AMC 推論負載。
- 儲存與分析佇列成長率。
- 真實事件的排隊延遲或丟棄率。

這是頻譜監測系統的可用性攻擊，應在有 backpressure 與事件保留策略時評估，而不只報告分類準確率。

### G3：Event bridging（事件橋接／錯誤合併）

若兩個合法 burst 中間的安靜間隔原本會被判為兩個事件，攻擊者可在間隔中發射足以維持門檻以上的能量，或把兩個區域的距離縮短至 `merge_gap` 以內，使事件被錯誤合併。

安全後果包括：

- 事件數與時間軸錯誤。
- AMC 視窗同時包含不同發射器或不同調變。
- 事件層彙整失去意義。
- 調查人員無法正確重建發射順序。

此攻擊不需要相位同步，只需要粗略知道事件間隔與門檻。

### G4：Boundary extension（邊界延伸與切窗偏移）

攻擊者在合法 burst 前後加入低功率前綴／尾綴，使平滑能量偵測器提早開啟或延後關閉。即使事件仍被偵測，固定從區域起點擷取的 128-sample 視窗可能只包含部分合法訊號。

量測指標應包括：

- 起始與結束邊界誤差。
- 所選視窗中的合法訊號覆蓋率。
- AMC 準確率與棄權率。
- 攻擊者每延伸一個 sample 所需的接收端能量。

純加性且非同步的 A1 攻擊者通常較容易延伸事件，而不容易精準造成事件內部的低能量切割。若研究「事件分裂」，必須說明是透過門檻污染造成弱區段掉出、還是採用需要精密同步的相消攻擊。

### G5：Max-energy window hijacking（最大能量視窗劫持）

當分段器在事件內選擇平均功率最高的 128-sample 視窗時，攻擊者可插入一個短而較強的 burst，使被選視窗集中在攻擊波形而非合法訊號上。

這是非常實際的前處理攻擊，因為攻擊者不必讓整個事件消失，只需改變候選視窗的相對能量排序。應比較：

- `naive` 與 `max-energy` 的攻擊成功率。
- 單一視窗與多重疊視窗彙整。
- 攻擊 pulse 長度、位置、峰值功率及平均 PSR。
- 是否可由峰均比或視窗間不一致偵測。

### G6：AMC evasion／targeted misclassification

攻擊者在事件存在且視窗已形成的情況下，使 AMC 輸出錯誤類別、指定目標類別或低信心結果。主要實驗不把數位 \(L_p\) norm 當作唯一限制，還要報告：

- 接收端 PSR、SJR 與 JNR。
- 攻擊佔用頻寬及頻譜遮罩。
- 時間與頻率偏移敏感度。
- 通道估計誤差下的成功率。
- 若訊號可解調，報告 EVM 與 BER。

針對 Top-K 或 Adaptive-K 的攻擊必須對完整防禦最佳化；只攻擊未防禦 AWN 後再套用 Top-K，僅屬防禦未知基準。

### G7：Defense-router manipulation（防禦路由操控）

若系統依頻譜平坦度、信心或其他統計量選擇 K 或決定是否啟動防禦，攻擊者可使路由器選錯分支：

- 讓惡意樣本看似乾淨而繞過防禦。
- 讓正常事件反覆觸發高成本防禦，造成延遲 DoS。
- 操控 K，使合法訊號的重要頻率成分被移除。

評估時應把路由決策納入攻擊目標，而不是假設路由器不可微分或不公開。

### G8：Evidence ambiguity（證據污染）

攻擊者不一定要成功誤分類。只要使保存的事件包含多個重疊來源、強攻擊 pulse 或錯誤 metadata 對應，就可能增加事後鑑識困難。系統因此必須保存足夠的事件前後 guard samples、擷取健康狀態及未經防禦修改的原始 IQ。

## 8. 不應作為主要實際攻擊的假設

### 8.1 完美相消

加性 RF 攻擊者若要降低合法訊號能量，必須在接收器位置產生幅度相等、相位相反的波形，並追蹤通道、CFO、時鐘與合法資料。對一般附近 SDR 攻擊者而言非常困難。

因此：

- 可把完美或近似相消列為 A0／強同步上界。
- 不應把它描述為 A1 攻擊者的預設能力。
- 主要實際隱藏攻擊應優先研究噪聲底污染、門檻操控與視窗劫持。

### 8.2 任意覆寫 ADC 樣本

直接把精確 \(\delta\) 加到接收端 tensor 是數位實驗模型，不等同 OTA。任何實體可行性結論都必須通過獨立發射器與實際通道驗證。

### 8.3 防禦保密

確定性的偵測、Top-K 與路由規則不應假設永久保密。主要安全結論使用 A1 白箱或近白箱設定；保密設定只能作為次要灰箱比較。

## 9. 攻擊限制與可重現參數

每次 RF 攻擊實驗至少固定並報告：

| 類別 | 必須報告的參數 |
|---|---|
| 接收器 | SDR 型號、樣本率、中心頻率、類比／數位增益、濾波器、ADC 位元、時鐘來源 |
| 合法訊號 | 調變、符號率、頻寬、burst 長度、接收功率、SNR |
| 攻擊訊號 | 波形、頻寬、burst 長度、duty cycle、接收功率、PSR／SJR／JNR |
| 通道 | 纜線／OTA、衰減、距離、是否有 LOS、多徑條件、通道估計方法 |
| 同步誤差 | 時間偏移、CFO、相位偏移、觸發延遲及 jitter |
| 系統 | 偵測視窗、噪聲估計長度、門檻、遲滯、`min_region_len`、`merge_gap`、分段策略 |
| 模型 | checkpoint 雜湊、前處理、視窗長度、backend、seed |
| 最佳化 | 目標函數、步數、步長、重啟次數、EOT 樣本數、查詢預算 |

不能只報告 min-max 正規化空間中的 \(\epsilon\)。該數值可用於重現數位基準，但不表示實際發射功率或 OTA 隱蔽性。

## 10. 防禦安全需求

### SR1：可靠活動偵測

在定義的 SNR、SJR、頻寬與通道條件下，合法事件偵測率不得低於門檻，且噪聲底更新不能被低成本長時攻擊任意抬高。

### SR2：受控誤報負載

系統必須限制每個來源／頻段／時間窗造成的高成本分類與告警負載，同時保留可疑事件摘要，避免 rate limiting 反而成為刪除證據的工具。

### SR3：事件邊界可追溯

保存偵測前後 guard samples、原始區域、合併前區域及最終分段，讓分析者可重建演算法如何形成事件。

### SR4：模型失效不可偽裝成正常推論

真實 AWN 載入失敗、dummy fallback、NaN logits 或 backend 例外必須輸出「模型故障」，不能輸出看似正常的 modulation label。

### SR5：允許棄權但避免無限棄權 DoS

棄權可降低錯誤接受，但攻擊者也可能故意讓所有事件棄權。系統需同時報告：

- 錯誤接受率。
- 乾淨事件棄權率。
- 攻擊事件召回率。
- 每分鐘棄權事件數及分析負載。

### SR6：完整證據保留

防禦前後的視窗、事件 metadata、模型／防禦輸出及設定必須具有共同 event ID。防禦模組不得只保留「修復後」訊號而丟棄原始證據。

## 11. 實驗矩陣

### 11.1 最小可行數位實驗

對每個 modulation、SNR 與 seed，測試：

1. 無攻擊。
2. 噪聲底污染。
3. 假事件洪泛。
4. 事件橋接。
5. 邊界延伸。
6. 最大能量視窗劫持。
7. 防禦未知 AMC 攻擊。
8. 完整管線自適應攻擊。

比較 `naive`、`max-energy`、多重疊視窗、固定 Top-K、Adaptive-K 及棄權策略。

### 11.2 纜線實驗

```text
合法 SDR TX ---- attenuator ----\
                               combiner -> SDR RX -> 正式監測管線
攻擊 SDR TX ---- attenuator ----/
```

纜線實驗可精確控制兩個來源在接收端的功率，且不會向外輻射。逐步掃描：

- SNR：由模型可辨識區到低 SNR 區。
- SJR／PSR：由攻擊無效到攻擊成功。
- CFO、時間偏移與觸發延遲。
- 攻擊 duty cycle 與持續時間。

### 11.3 屏蔽 OTA 實驗

在法規允許且屏蔽良好的環境中，加入：

- 天線位置與距離變化。
- LOS／簡單遮蔽物。
- 重複擷取與通道變動。
- 攻擊波形 transferability。

主要結果需同時報告成功與失敗案例，不能只挑選成功的通道 realization。

## 12. 評估指標

### 12.1 頻譜感知／活動偵測

- Probability of Detection（\(P_d\)）。
- Probability of False Alarm（\(P_{fa}\)）或每小時假事件數。
- Time to Detect。
- 起始／結束邊界誤差。
- 事件 IoU。
- 分裂率、合併率及漏事件率。
- 噪聲底估計偏移量與恢復時間。

### 12.2 AMC 與事件決策

- 乾淨準確率與強健準確率。
- 目標／非目標攻擊成功率。
- 事件層而非只看視窗層的準確率。
- 錯誤接受率、棄權率及攻擊事件召回率。
- 模型、防禦與視窗間的不一致率。

### 12.3 可用性與營運影響

- 每分鐘事件與告警數。
- 每分鐘 AMC 推論次數。
- 分析佇列長度及等待時間。
- dropped samples、backpressure 與證據丟失率。
- CPU／GPU、記憶體、儲存與端到端延遲。

### 12.4 RF 可行性

- PSR、SJR、JNR。
- 攻擊頻寬與頻譜外洩。
- EVM 與 BER（若有可解調訊號）。
- CFO、時間偏移、相位誤差與通道變動下的成功率。

## 13. 明確排除範圍

除非後續另行實作與驗證，本研究不主張處理：

- 接收主機、作業系統或模型供應鏈被入侵。
- 密碼學或通訊協定層的身分冒用。
- 對公共頻段的未授權干擾。
- 多站定位、測向或發射器指紋識別。
- 尚未實作的 demodulation、CRC、協定解析或自主頻譜配置。
- 未有 channelizer 時的真正寬頻、多子通道頻譜佔用推論。
- 一般 A1 攻擊者可進行完美相位同步相消的假設。

## 14. 論文可直接使用的威脅模型摘要

本研究考慮一個被動式射頻監測節點，其 SDR 前端輸出單一預先通道化的複數基頻串流。監測管線先估計噪聲底並以能量門檻建立事件，再進行區域合併、視窗選擇、AWN 調變分類、頻域防禦與事件層棄權。主要攻擊者是一個位於接收範圍內、使用獨立商用 SDR 的加性 RF 發射者。攻擊者知道管線設計與模型，可估計自身通道並觀察合法活動，但不能修改接收主機、模型、擷取檔或事件資料庫，也不假設能與合法發射器精確相位同步。攻擊受到接收端功率、頻寬、duty cycle、總發射時間、CFO、觸發延遲及通道不確定性限制。攻擊目標包括污染噪聲底以隱藏弱事件、製造假佔用造成分析資源耗盡、橋接相鄰事件、偏移事件邊界、劫持最大能量視窗，以及針對完整防禦進行 AMC 誤分類或棄權 DoS。數位 tensor 注入僅作為演算法上界；所有實體可行性結論皆須經纜線或屏蔽 OTA 實驗驗證。

此威脅模型的關鍵是：把攻擊者放在 RF 通道外部，而非假設它能任意覆寫分類器 tensor；把頻譜感知的偵測、噪聲估計、事件形成與視窗選擇納入攻擊面，而非只研究已完美切割的 128-sample AMC 樣本。
